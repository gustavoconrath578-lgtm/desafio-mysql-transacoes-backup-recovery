# Desafio MySQL - Transações, Backup e Recovery

## Sobre o projeto

Este projeto foi desenvolvido como parte de uma atividade da faculdade, com o objetivo de praticar transações, procedimentos armazenados e recuperação de dados utilizando o MySQL.

Para realizar a atividade, foi utilizado um banco de dados de e-commerce, simulando operações com produtos, pedidos e estoque.

## O que foi feito

- **Parte 1 - Transações:** utilização de COMMIT, ROLLBACK e SAVEPOINT para controlar alterações no banco de dados.
- **Parte 2 - Procedures:** criação de uma procedure com tratamento de erros, permitindo desfazer operações quando necessário.
- **Parte 3 - Backup e Recovery:** utilização do mysqldump para gerar um backup dos bancos de dados e permitir sua restauração.

## Ferramentas utilizadas

- MySQL Server 8.0
- MySQL Workbench
- SQL
- GitHub

## Arquivos do projeto

- `atividade_transacoes.sql` - Contém os códigos das transações, procedures e demais operações.
- `backup_multibancos.sql` - Arquivo de backup dos bancos de dados.

## Conclusão

A atividade ajudou a entender melhor como funcionam as transações no MySQL e a importância de controlar as alterações feitas no banco de dados. Também foi possível praticar recursos de backup e recuperação, que são importantes para evitar a perda de informações.
